### Open work on this profile

| Repository | What it is |
|---|---|
| [CAN-BUS-Embedded-Guide](https://github.com/gitarthagogoi/CAN-BUS-Embedded-Guide) | A guide to debugging CAN on STM32 and ESP32. It covers the basics, bit timing and sample point, and an error checklist. A case study traces a bus that worked in loopback but got no ACK in normal mode to the wiring of the transceiver's Rs pin. STM32 and ESP32 (TWAI) example code is in progress. |
| [Hybrid IRS baseline code](https://github.com/gitarthagogoi/Optimizing-energy-and-spectral-efficiency-in-hybrid-IRS-assisted-MU-MISO-systems) | MATLAB benchmark precoders and the channel model for the *Physical Communication* paper. The proposed precoder is available on request for academic use. |
| [Active IRS MU-MISO](https://github.com/gitarthagogoi/Active-IRS-Aided-Wireless-Communication-System) | Joint beamforming and IRS precoding using fractional programming, alternating optimization and WMMSE. It compares passive, ideal active and practical active surfaces. |
| [Hybrid IRS simulation framework](https://github.com/gitarthagogoi/Joint-Beamforming-and-Optimization-for-Hybrid-IRS-assisted-Wireless-Communication-System) | A modular MATLAB testbed for active and passive IRS with hardware power modelling. The core pipeline runs; joint optimization and documentation are in progress. |
